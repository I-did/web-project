# Нефункциональные требования и критерии приёмки

| ID НФТ | Связанные БТ | Нефункциональное требование | Метрика / КП-НФТ | Метод проверки |
|---|---|---|---|---|
| НФТ‑01 | [БТ‑01](business.md#bt-01), [БТ‑12](business.md#bt-12), [БТ‑17](business.md#bt-17), [БТ‑18](business.md#bt-18) | Адаптивность интерфейса | [КП-НФТ‑01](#kp-nft-01): На ширине экрана от 360 px не появляется горизонтальная прокрутка из-за основного содержимого. | Открыть страницы анкеты, кабинета, питания и тренировок в эмуляции 360, 768, 1280 px; проверить прокрутку. |
| НФТ‑02 | [БТ‑01](business.md#bt-01), [БТ‑12](business.md#bt-12), [БТ‑17](business.md#bt-17), [БТ‑18](business.md#bt-18) | Скорость отображения ключевых страниц | [КП-НФТ‑02](#kp-nft-02): При контрольном локальном тесте на согласованном стенде ключевая страница становится доступной для взаимодействия не позднее 3 секунд в 9 из 10 прогонов. | Провести 10 одинаковых прогонов в браузере на согласованном стенде; замерить время до доступности интерфейса. |
| НФТ‑03 | [БТ‑02](business.md#bt-02), [БТ‑03](business.md#bt-03), [БТ‑12](business.md#bt-12), [БТ‑13](business.md#bt-13), [БТ‑14](business.md#bt-14), [БТ‑16](business.md#bt-16) | Защита персональных данных | [КП-НФТ‑03](#kp-nft-03): Анкета и данные прогресса одного тестового участника недоступны другому участнику без разрешения. | Создать 2 тестовые учётные записи; попытаться открыть данные другого участника по ссылке и прямому запросу. |
| НФТ‑04 | [БТ‑13](business.md#bt-13), [БТ‑14](business.md#bt-14), [БТ‑20](business.md#bt-20) | Сохранность данных прогресса | [КП-НФТ‑04](#kp-nft-04): После обновления страницы уже успешно сохранённые записи веса и замеров остаются доступными; сброс анкеты не удаляет их без отдельно подтверждённого правила. | Создать записи, обновить страницу и войти заново; проверить сохранность. Правило сброса согласовать отдельно. |
| НФТ‑05 | [БТ‑17](business.md#bt-17), [БТ‑18](business.md#bt-18), [БТ‑19](business.md#bt-19) | Доступность базового управления | [КП-НФТ‑05](#kp-nft-05): Ключевые действия на страницах выполняются клавиатурой; виден индикатор фокуса. | Пройти основные сценарии клавишами Tab, Shift+Tab, Enter/Space без мыши. |
| НФТ‑06 | [БТ‑21](business.md#bt-21), [БТ‑22](business.md#bt-22), [БТ‑05](business.md#bt-05), [БТ‑08](business.md#bt-08) | Целостность справочников контента | [КП-НФТ‑06](#kp-nft-06): Каждая запись блюда/тренировки, использованная в плане, существует в соответствующей базе и имеет необходимые для показа поля. | Сформировать тестовый план и автоматически сверить ID элементов и обязательные поля с базой. |
| НФТ‑07 | [БТ‑17](business.md#bt-17), [БТ‑18](business.md#bt-18) | Устойчивость отображения внешних медиа | [КП-НФТ‑07](#kp-nft-07): Если видео недоступно, страница тренировок остаётся доступной и показывает сообщение об ошибке вместо пустого блока. | Заменить адрес тестового видео недоступным и проверить интерфейс и остальные функции. |
| НФТ‑08 | [БТ‑01](business.md#bt-01), [БТ‑05](business.md#bt-05), [БТ‑08](business.md#bt-08), [БТ‑12](business.md#bt-12) | Совместимость браузеров | [КП-НФТ‑08](#kp-nft-08): Основные сценарии выполняются без блокирующих дефектов в актуальных настольных Chrome и Firefox. | Провести сквозные проверки анкеты, планов и кабинета в указанных браузерах. |

## Реестр критериев приёмки НФТ

| ID КП-НФТ | НФТ | Метрика (условие успешной приёмки) | Метод проверки |
|---|---|---|---|
| <a id="kp-nft-01"></a>КП-НФТ‑01 | НФТ‑01 | На ширине экрана от 360 px не появляется горизонтальная прокрутка из-за основного содержимого. | Открыть страницы анкеты, кабинета, питания и тренировок в эмуляции 360, 768, 1280 px; проверить прокрутку. |
| <a id="kp-nft-02"></a>КП-НФТ‑02 | НФТ‑02 | При контрольном локальном тесте на согласованном стенде ключевая страница становится доступной для взаимодействия не позднее 3 секунд в 9 из 10 прогонов. | Провести 10 одинаковых прогонов в браузере на согласованном стенде; замерить время до доступности интерфейса. |
| <a id="kp-nft-03"></a>КП-НФТ‑03 | НФТ‑03 | Анкета и данные прогресса одного тестового участника недоступны другому участнику без разрешения. | Создать 2 тестовые учётные записи; попытаться открыть данные другого участника по ссылке и прямому запросу. |
| <a id="kp-nft-04"></a>КП-НФТ‑04 | НФТ‑04 | После обновления страницы уже успешно сохранённые записи веса и замеров остаются доступными; сброс анкеты не удаляет их без отдельно подтверждённого правила. | Создать записи, обновить страницу и войти заново; проверить сохранность. Правило сброса согласовать отдельно. |
| <a id="kp-nft-05"></a>КП-НФТ‑05 | НФТ‑05 | Ключевые действия на страницах выполняются клавиатурой; виден индикатор фокуса. | Пройти основные сценарии клавишами Tab, Shift+Tab, Enter/Space без мыши. |
| <a id="kp-nft-06"></a>КП-НФТ‑06 | НФТ‑06 | Каждая запись блюда/тренировки, использованная в плане, существует в соответствующей базе и имеет необходимые для показа поля. | Сформировать тестовый план и автоматически сверить ID элементов и обязательные поля с базой. |
| <a id="kp-nft-07"></a>КП-НФТ‑07 | НФТ‑07 | Если видео недоступно, страница тренировок остаётся доступной и показывает сообщение об ошибке вместо пустого блока. | Заменить адрес тестового видео недоступным и проверить интерфейс и остальные функции. |
| <a id="kp-nft-08"></a>КП-НФТ‑08 | НФТ‑08 | Основные сценарии выполняются без блокирующих дефектов в актуальных настольных Chrome и Firefox. | Провести сквозные проверки анкеты, планов и кабинета в указанных браузерах. |
