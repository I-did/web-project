# Функциональные требования и критерии приёмки

ФТ описывают **что делает система**. Для каждого ФТ указан родительский БТ и КП-БТ из [business.md](business.md). Собственный КП-ФТ создаётся только при детализации, выходящей за рамки родительского критерия.

|---|---|---|---|

| ФТ‑02 | [БТ‑02](business.md#bt-02) | Проверять введённые вес, желаемый вес, рост и возраст и блокировать продолжение при некорректных значениях. | [КП-БТ‑02](business.md#kp-bt-02) |
| ФТ‑03 | [БТ‑03](business.md#bt-03) | Получать пол и признак грудного вскармливания и передавать их в расчёт. | [КП-БТ‑03](business.md#kp-bt-03) |
| ФТ‑04 | [БТ‑04](business.md#bt-04) | Рассчитывать суточные калории, белки, жиры и углеводы по согласованной формуле. | [КП-БТ‑04](business.md#kp-bt-04) |

## Дополнительные критерии приёмки ФТ

| ID | ФТ | Проверяемое условие |
|---|---|---|
| <a id="kp-ft-11"></a>КП-ФТ‑11 | ФТ‑11 | При выборе «дом» → «без инвентаря» программа не содержит упражнений, требующих дополнительного оборудования. |
| <a id="kp-ft-21"></a>КП-ФТ‑21 | ФТ‑21 | При переключении между днями недели отображаются соответствующие им приёмы пищи из сформированного плана. |
| <a id="kp-ft-27"></a>КП-ФТ‑27 | ФТ‑27 | В анкете доступны поля цели, стажа тренировок и активности; введённые значения сохраняются для дальнейшего подбора плана. |
| <a id="kp-ft-28"></a>КП-ФТ‑28 | ФТ‑28 | Выбранные физические ограничения сохраняются в данных анкеты и доступны механизму подбора тренировок. |

## Открытые вопросы

- Требуется утвердить формулу КБЖУ, граничные значения полей анкеты и правила формирования замены блюда. До этого детализировать тесты дальше нельзя без допущений.
- Для ФТ‑17 (фото-прогресс) обязательность реализации зависит от решения по опциональному БТ‑16.
- В ФТ‑26 сохранено требование о подготовленной тренером базе тренировок. КП-БТ‑22 в источнике проверяет только видео; полноту проверки состава базы нужно согласовать.
