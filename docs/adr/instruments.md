Общие для всех вариантов: Vue 3 + Tailwind на фронтенде. Различается бэкенд-платформа.

## Обоснование выбора Vue 3 для нашего проекта

- Низкий порог входа и высокая скорость разработки
- Встроенная рекативность и богатый набор инструментов из коробки
- Оптимальный баланс производительности и размера
- Полная совместимость с экосистемой Directus

Vue 3 обеспечит хороший баланс между скоростью разработки, простотой поддержки и архитектурной совместимостью с выбранным бэкендом (Directus).

## Tailwind

Так же, предполагается прагматичный выбор в пользу CSS фреймворка Tailwind. Он предоставит стили внутри шаблона компонентов. Позволит создать нам красивый и единообраный интерфейс без дизайнера, требует минимум усилий от команды, для MVP очень хорошо

## Сравнение комбинаций инструментов

### Vue 3 + Tailwind + Directus

- Directus - database-frist headless CMS, оборачивает SQL БД, генерирует REST API
- Админка из коробки, встроенная аутентификация
- Права пользователей гибко настраиваются через админку, можно настраивать действия, взаимодействие с конкретными полями, условные фильтры
- Через хуки можно добавлять кастомную логику

### Vue 3 + Tailwind + Python + FastAPI

- FastAPI дает полный контроль над структурой
- Есть шаблоны модульного монолита
- Админки из коробки нет, нужно подключать и настраивать стороннее решение
- Управление правами пользователей настраивается вручную или через сторонние библиотеки

### Vue 3 + Tailwind + PHP + Laravel

- Есть встроенные механизмы аутентификации
- Роли и права через пакеты
- Админки из коробки нет, но есть много хороших сторонних решений

## Обоснование выбора Directus для нашего проекта

- Автоматически генерирует REST API
- Готовая админ-панель
- Контроль доступа из коробки
- Расширяемость
- Очень быстрый и простой старт
- Однородность frontend/backend
