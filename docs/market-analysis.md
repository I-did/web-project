## Ниша

Четырёхнедельная программа для взрослых, которые готовят самостоятельно и хотят получить питание и тренировки по анкете. Основной акцент - подбор рациона при нескольких пищевых исключениях и удобная замена блюд с контролем КБЖУ. В части тренировок – подбор программы с учётом уровня подготовки, физических ограничений, места занятий и доступного инвентаря.

## Частично закрытые потребности

1. **Рацион при сочетании нескольких ограничений.** Некоторые планы Lifesum недоступны при определённых исключениях. Eat This Much признаёт, что строгие настройки могут мешать попаданию в цели по БЖУ. [Lifesum](https://help.lifesum.com/en/article/requirements-for-all-the-meal-plans-mnl9gp/), [Eat This Much](https://help.eatthismuch.com/help/the-generator-isnt-hitting-my-target-macros-whats-going-on).

2. **Замены без самостоятельного пересчёта.** В FatSecret проверка равноценности замены остаётся пользователю; BeFit допускает изменение калорийности до 30%. [FatSecret](https://www.fatsecret.com/fatsecret-app-help/getting-started-with-premium/how-to-use-dietician-designed-meal-plans), [BeFit](https://letbefit.ru/faq/).

3. **Исключения для отдельных приёмов пищи.** Например, рыба допустима дома, но нежелательна в рабочем обеде. Eat This Much предлагает для такого сценария обходной путь вместо отдельной настройки. [Описание ограничения](https://help.eatthismuch.com/help/can-i-exclude-foods-only-from-particular-meals).

4. **Тренировки с учётом ограничений.** Freeletics позволяет исключать отдельные упражнения не во всех программах. [Описание ограничения](https://help.freeletics.com/hc/en-us/articles/360019851400-Can-I-exclude-certain-exercises-from-my-Training-Journey).
