# Тест-кейсы по критериям приёмки

> Статус: проект тестовой документации, сценарии проверок. Источники: [БТ и КП-БТ](../requirements/business.md), [ФТ и КП-ФТ](../requirements/functional.md), [НФТ и КП-НФТ](../requirements/non-functional.md).

## Правила

- `T-XX` — функциональная проверка ровно одного КП-БТ или КП-ФТ. Если КП связан с несколькими ФТ, они перечислены в колонке «Что проверяет».
- `TN-XX` — проверка ровно одного КП-НФТ с измеримым ожидаемым результатом.
- Там, где не определены формула, границы вводимых значений, политика данных или условия стенда, указаны обязательные предусловия для согласования; значения не придуманы.
- В MVP‑1 T-08…T-11, T-13…T-16, T-18, T-20, T-22, T-23, T-26 и соответствующие TN не выполняются до внедрения отложенной функции. БТ‑16 (фото-прогресс) опционально: кейс T-16 применяется только при включении функции в проверяемый релиз.
