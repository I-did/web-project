# User Stories

## Роли
Основная пользовательская роль — **участник** (клиент сервиса). Для MVP также есть менеджер, который приглашает оплатившего участника в Directus. 
Внутренние роли (нутрициолог, тренер) не работают в системе: они наполняют базы приёмов пищи и тренировок.

## Формат
**Как** [роль], **я хочу** [действие], **чтобы** [ценность].

## Покрытие БТ
27 бизнес-требований покрыты 23 пользовательскими историями. Применены три логические группировки:
- **US-06** — БТ‑06 + БТ‑07 (пищевые ограничения и уточнение исключений — один пользовательский сценарий);
- **US-07** — БТ‑08 + БТ‑09 + БТ‑10 (условия тренировок: ограничения, место, инвентарь);
- **US-10** — БТ‑13 + БТ‑14 (сохранение веса и замеров — один сценарий ведения дневника).
