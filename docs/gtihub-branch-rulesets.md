# Ветвление и правила слияния

Настроены классические правила для защиты main ветки:

- Защита от случайного удаления
- Перед слиянием требуется PR
- Для PR требуется хотя бы один одобряющий
- Включена линейная истоия (squash/rebase вместо merge)
- Требуется прохождение через линтеры
- Запрет force push
- checks добавлены
