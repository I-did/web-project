## 1. Модули и их контракты

### 1.1. Модули

| Модуль | Отвечает за | Использует |
|---|---|---|
| `shared` | общие типы и формат ошибок | — |
| `auth` | регистрация, вход, текущий пользователь | `shared` |
| `questionnaire` | шаги, ветвления, валидация, сброс | `shared`, `auth` |
| `nutrition` | расчёт КБЖУ, рацион, замена блюда, корзина | `shared`, `questionnaire` (чтение) |
| `workouts` | программа тренировок | `shared`, `questionnaire` (чтение) |
| `progress` | вес, замеры, график, фото | `shared`, `auth` |

Правило: модуль обращается к другому только через его контракт, а не к его данным напрямую.

### 1.2. Общие типы

| Тип | Допустимые значения |
|---|---|
| Цель | снижение, поддержание, набор (коэффициенты 0.8 / 1.0 / 1.1) |
| Пол | мужской, женский |
| Место занятий | дом, зал |
| Тип приёма пищи | завтрак, перекус 1, обед, перекус 2, ужин |
| КБЖУ-макросы | белки, жиры, углеводы в граммах |
| Ошибка | список ошибок с сообщением и кодом, формат Directus |

### 1.3. Операции модулей

| Модуль | Операция | Вход | Выход | ФТ |
|---|---|---|---|---|
| `auth` | зарегистрироваться | email, пароль | — | — |
| `auth` | войти | email, пароль | сессия | — |
| `auth` | выйти | — | — | — |
| `auth` | получить текущего пользователя | — | идентификатор, email | ФТ-13 |
| `questionnaire` | отправить анкету | данные анкеты (1.4) | результат расчёта (1.5) | ФТ-04, 05 |
| `questionnaire` | получить сохранённую анкету | — | данные анкеты или пусто | ФТ-13 |
| `questionnaire` | сбросить анкету | — | — | ФТ-24 |
| `nutrition` | получить рацион | — | план питания на 4 недели | ФТ-05, 18 |
| `nutrition` | получить приёмы пищи дня | неделя, день | список приёмов пищи | ФТ-21 |
| `nutrition` | заменить приём пищи | идентификатор записи плана | новый приём пищи | ФТ-20 |
| `nutrition` | получить корзину недели | неделя | список продуктов: название, количество, единица | ФТ-19 |
| `workouts` | получить программу | — | тренировки по неделям | ФТ-22 |
| `progress` | добавить вес | дата, вес | запись веса | ФТ-14 |
| `progress` | получить историю веса | — | список записей | ФТ-14 |
| `progress` | добавить замеры | дата, значения замеров | запись замеров | ФТ-15 |
| `progress` | получить историю замеров | — | список записей, график строится от 2 записей | ФТ-15, 16 |

Одна запись веса и одна запись замеров в календарный день.

### 1.4. Данные анкеты

| Поле | Тип | Условие |
|---|---|---|
| Цель | цель | обязательно |
| Пол | пол | обязательно |
| Вес, желаемый вес, рост, возраст | числа | обязательно, диапазоны не заданы |
| Грудное вскармливание | да / нет | только для женского пола |
| Активность | уровень активности | обязательно |
| Пищевые ограничения | список категорий | не более 5 |
| Исключаемые подкатегории | список (молочные, мясные, рыбные) | по выбранным категориям |
| Физические ограничения | список из справочника | — |
| Место занятий | дом / зал | обязательно |
| Домашний инвентарь | список или «без инвентаря» | только для места «дом» |
| Проблемные зоны | список из справочника | — |

### 1.5. Результат расчёта и план

| Объект | Состав |
|---|---|
| Результат расчёта | BMR, TDEE, целевая калорийность, макросы, план питания, программа тренировок |
| План питания | 4 недели × 7 дней; в плане 28 завтраков, 28 обедов, 28 ужинов и 56 перекусов |
| Приём пищи в плане | идентификатор записи плана, тип приёма пищи, блюдо |
| Блюдо | идентификатор, название, калории, макросы, рецепт, ингредиенты (название, количество, единица) |
| Программа тренировок | 4 недели; в неделе список тренировок |
| Тренировка | идентификатор, название, упражнения (название, ссылка на видео) |

## 2. HTTP API

Все запросы, кроме входа и регистрации, идут с токеном авторизации. Ошибки приходят в формате Directus.

### 2.1. Эндпоинты

| Метод и путь | Назначение | ФТ |
|---|---|---|
| `POST /auth/login`, `POST /auth/logout` | вход и выход | — |
| `GET /users/me` | текущий пользователь | ФТ-13 |
| `GET /items/dish_categories` | справочник категорий для шагов 6-7 | ФТ-06, 07 |
| `POST /custom/calculate-nutrition` | расчёт КБЖУ, подбор рациона и тренировок, сохранение | ФТ-04, 05, 08, 25, 26 |
| `POST /custom/questionnaire/reset` | сброс анкеты | ФТ-24 |
| `GET /items/user_meals` | приёмы пищи по неделе и дню | ФТ-18, 21 |
| `POST /custom/meals/{id}/replace` | замена приёма пищи | ФТ-20 |
| `GET /custom/nutrition/basket?week=` | продуктовая корзина недели | ФТ-19 |
| `GET /items/user_workouts` | тренировки по неделям | ФТ-22 |
| `GET, POST /items/weight_entries` | вес | ФТ-14 |
| `GET, POST /items/measurement_entries` | замеры | ФТ-15, 16 |
| `GET /items/app_settings` | ссылка на Telegram-чат | ФТ-23 |

### 2.2. Расчёт плана

`POST /custom/calculate-nutrition`

- **Запрос:** данные анкеты (раздел 1.4).
- **Ответ 200:** поля `bmr`, `tdee`, `target_calories`, `macros`, `meal_plan`, `workout_plan`.
- **Пример значений** из `architecture.md`: BMR 1420.25, TDEE 1952.84, целевая калорийность 1562 ккал, белки 117.2 г, жиры 43.4 г, углеводы 175.7 г.

| HTTP | Код | Когда |
|---|---|---|
| 400 | `INVALID_PAYLOAD` | значения вне допустимых диапазонов, больше 5 категорий |
| 401 | `UNAUTHORIZED` | нет или просрочен токен |
| 422 | `NOT_ENOUGH_DISHES` **[Г]** | после фильтров в базе недостаточно блюд |

## 3. Экраны вне анкеты

### 3.1. Экраны

| Экран | Что показывает | ФТ |
|---|---|---|
| Вход и регистрация | email и пароль | — |
| Результат расчёта | КБЖУ после анкеты | ФТ-04 |
| Личный кабинет | данные анкеты, ссылка на Telegram, сброс анкеты | ФТ-13, 23, 24 |
| План питания | неделя и день, карточки приёмов пищи, кнопка «Заменить», корзина, рекомендации | ФТ-18..21 |
| Тренировки | недели, список тренировок, видео | ФТ-22 |
| Прогресс | ввод веса и замеров, график, фото (опционально) | ФТ-14..17 |

### 3.2. Общие состояния

| Состояние | Требование |
|---|---|
| Загрузка | индикатор, страница доступна не позднее 3 с (НФТ-02) |
| Пустые данные | сообщение и подсказка действия (например, для графика нужно минимум 2 записи) |
| Ошибка запроса | сообщение и повтор |
| Видео недоступно | сообщение об ошибке вместо пустого блока (НФТ-07) |
| Ширина от 360 px | без горизонтальной прокрутки (НФТ-01) |
