# Прототип «КБЖУ»

Это временное оформление до утверждения макета. Используются обычный CSS, Arial, белый фон и зелёный цвет для основных действий. SVG и сторонние UI-библиотеки не применяются.

Сохранены страницы и логика Vue: маршруты, анкета с ветвлением и проверкой полей, Pinia, сервисы API и состояния ошибок. Оплата и расчёт работают только при наличии настроенного сервера и необходимых переменных окружения.

В будущем можно заменить стили по дизайну из Figma, не переписывая функциональную логику.

Проверка из папки фронтенда:

```bash
npm ci
npm run build
npm run test:unit -- --run
```
